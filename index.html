Aide & raccourcis

RRM-FT Assistant utilise les données officielles FDA (aucun recalcul) pour évaluer les risques de traçabilité (FSMA 204).

  • Recherche : tapez dans la barre latérale pour filtrer les denrées.
  • FTL : badge vert = produit sur la Food Traceability List.
  • Score : valeur maximale parmi les paires danger.
  • Tri : cliquez sur l'en-tête d'une colonne.
  • Raccourcis : Ctrl+S enregistrer, Ctrl+E exporter, Échap fermer.
